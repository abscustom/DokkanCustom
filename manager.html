Card associations

Card Linker

Saved associations stay visible across the workspace while you select different cards. Choose a first portrait, then a target, and use Link Selected Pair to stage that exact reciprocal link. Cards can belong to multiple links; the lines show each saved or staged pair without adding implied relationships. Start Another Pair to select a different pair, and use Apply Changes to save all staged links.

Selection uses a bright blue FIRST ring and a gold TARGET ring with role labels; green portrait rings mark linked cards. Choose a first portrait, then a target. Link Selected Pair stages that exact edge. Clear Target keeps the first card; Clear Both cancels the current pair. Cards may have multiple links, and all saved or staged connectors remain visible. Dragging an unlinked coin onto the first card stages a link; dropping a linked coin into the removal area stages an unlink. Selection and movement alone never change or save relationships; Apply Changes saves staged work.
